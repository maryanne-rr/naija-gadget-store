# Product photo credits

Every photo in `public/products/` was downloaded from Wikimedia Commons and is
used under the licence listed here. Commons files are mostly CC BY-SA, which
requires crediting the photographer, so this file is not optional.

The first ten came from Unsplash (downloaded directly, no API key involved, so
the Unsplash licence applies: free to use, no attribution required). The rest
came from Commons.

Run `npm run photos:credits` to regenerate this file from the metadata stored in
`public/products/CREDITS.json`.
